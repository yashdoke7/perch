# PERCH

**A personal AI agent that is not trapped inside an application.**

It lives where your desktop lives — dormant in the background, summoned by a selection, a screenshot,
or a shortcut, anywhere in Windows. It answers in a slim panel beside your work and edits in place
where you were already working. When you want a full conversation, the same agent opens a proper
window.

Because it sits above your applications rather than inside one, it is the only place your personal
context can live once and be used everywhere.

> You pay for four AI assistants. None of them know you.
> PERCH is the one that does — and it works inside all of them.
